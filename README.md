# Exercism Backup Repo

This repository is a personal backup of my solutions to exercises completed on [Exercism](https://exercism.org), the open-source platform for hands-on programming practice and mentoring. It is not an official Exercism project—just a place to keep my submissions versioned and easy to browse.

## Layout

All exercises live under `solutions/`, grouped by language:

- `solutions/java/` – Java tracks and exercises
- `solutions/python/` – Python tracks and exercises

Each exercise folder typically contains the source files provided by Exercism plus my solution code and any notes specific to the exercise.

## How to use this repo

- **Browse examples:** Explore by language to see how I approached different problems.
- **Restore locally:** Clone the repo and open an exercise directory in your editor of choice. Follow the track’s README (usually included by Exercism) to run tests.
- **Add new solutions:** Drop the downloaded exercise from Exercism into the appropriate language folder, then commit the changes to keep the backup up to date.

## About Exercism

Exercism offers language-specific tracks with test-driven exercises and volunteer mentoring. Learn more or sign up at [exercism.org](https://exercism.org).
